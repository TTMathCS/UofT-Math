04

Adding A Future Course

Create its folder and course pages, then add one object to assets/courses.js. The catalog automatically adds the card, subject filter, search terms, and updated totals. Program requirements live separately in assets/programs.js; a course only lights up for a path once its code appears in that program's required or options list, and a route only suggests it once it appears in that route's picks.
