Subspaces, Span & Independence

The three ideas that organize a vector space from the inside: which subsets are themselves spaces, what a set of vectors generates, and when vectors carry genuinely independent information.

Why it matters & where it comes from
Why it exists

Span and independence are how we measure "how much" a set of vectors captures — without redundancy. They lead directly to the idea of a basis.

In the real world

Linear independence is feature redundancy in data science; the span of a dataset is the subspace it can represent. Dimensionality reduction (PCA) is exactly this language.

Story & open questions

These notions crystallized as mathematicians sought the smallest set of "directions" needed to describe a space — the search that produced the modern theory of dimension.

By the end you can
  • Test whether a subset is a subspace.
  • Describe the span of a set of vectors.
  • Decide linear independence.

Subspaces and span

Definition

$W\subseteq V$ is a subspace if it contains $0$ and is closed under addition and scalar multiplication. The span of $S$ is the set of all linear combinations of vectors in $S$ — the smallest subspace containing $S$.

Linear independence

Definition

$v_1,\dots,v_k$ are linearly independent if $c_1v_1+\cdots+c_kv_k=0$ forces every $c_i=0$. Otherwise one vector is a combination of the others.

Example

$(1,0),(0,1)$ are independent; $(1,2),(2,4)$ are dependent since the second is twice the first.

Common pitfalls

• A subspace must contain the zero vector.
• Independence is about the only solution being trivial.
• Span grows with more vectors; independence shrinks.

Practice

Practice 1

Is the set of polynomials with $p(0)=0$ a subspace of $P(\mathbb{R})$?

Answer
Yes — closed under $+$ and scalars, contains the zero polynomial.
Practice 2

Are $(1,1,0),(0,1,1),(1,0,-1)$ independent in $\mathbb{R}^3$?

Answer
No — the third equals the first minus the second.
Practice 3

What is $\operatorname{span}\{(1,0),(0,1)\}$?

Answer
All of $\mathbb{R}^2$.
